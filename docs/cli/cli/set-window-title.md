# `wezterm cli set-window-title TITLE`

{{since('20230408-112425-69ae8472')}}

Changes the title of a window. The window shows it in place of the active
pane's title until an application in that window sets a new title with an
escape sequence.

*Run `wezterm cli set-window-title --help` to see more help*
